FIELD GUIDE 02 · THE PROFILE LAB

PICK YOUR LOADOUT.
Know what it changes.

Profiles are curated bundles of Dolphin.ini and GFX.ini. They are starting points, not magic FPS switches. The best choice depends on the exact title, region, firmware, backend and what you value: speed, balance or accuracy.

Start with Default or Rt:Prime Standard. Change one variable at a time. A profile can improve one game and break another.
PROFILE FAMILIES

Three philosophies. Three tiers.

The family tiers are Lite / Standard / Max. Use the descriptions to understand intent; validate actual results through the Compatibility Database.

HOW TO CHOOSE

Recommended starting path.

These are safe decision rules, not a universal optimal-settings recipe.

Begin with Default

Use the safe baseline to confirm the game boots, video renders and input works. This gives you a known reference point.

Try Rt:Prime Standard

When you want a balanced everyday configuration, test the standard Prime tier. Record the result against the exact game ID and region.

Use Rt:Boost only when evidence supports it

Try Lite before Standard or Max. Watch for glitches, missing effects, audio instability, crashes and uneven frame pacing. Higher tier does not mean better for every title.

Use Rt:Pure when accuracy is the priority

When speed-oriented hacks cause rendering errors or gameplay issues, compare against the accuracy-focused family.

Apply fixes per game whenever possible

Black Screen Fix, Compatibility and Sweet Spot are targeted baselines. Avoid globally changing settings to solve one game's problem.

IMPORTANT CONFIG RULES

INI files are not interchangeable.

Core vs graphics

Each profile contains Dolphin.ini and GFX.ini. The profile manager applies both to the active Config directory and backs up the previous live configuration.

Locked canonical profiles

Family profiles are locked against direct overwrite. Save personal changes as a new Custom profile rather than modifying canonical presets.

GameSettings section names

For per-game video hacks use [Video_Hacks], not [Hacks]. Dolphin silently ignores the wrong section in GameSettings.

The old underclock labels in historical profiles are not universal tuning advice. Verify the actual profile INI and current metadata before recommending a numeric value.
