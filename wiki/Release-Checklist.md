# Release Checklist

- Confirm platform, firmware and version.
- Update changelog and version sources.
- Run relevant tests, syntax checks and package verification.
- Inspect package contents and checksums.
- Capture UI evidence; label desktop versus device captures.
- Verify install, upgrade and uninstall on disposable targets where possible.
- Document external dependencies and unverified combinations.

Never describe an emulator, syntax or dry-run result as a physical-device test.
