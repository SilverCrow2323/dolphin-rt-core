# Rating Guide

Use the lowest rating that accurately describes the tested experience. Ratings should reflect real gameplay, not theoretical compatibility.

| Rating | Meaning | Boot | Playability |
|---:|---|---|---|
| 0 | Does not boot / no usable start | No boot | No |
| 1 | Starts or reaches a stage, then crashes or becomes unusable | Crash | No |
| 2 | Boots, but performance or defects make it unplayable | Boots | No |
| 3 | Playable with meaningful issues, slowdowns or workarounds | Boots | Yes, with issues |
| 4 | Playable with minor issues that do not usually block progress | Boots | Yes |
| 5 | Excellent result for the stated device and settings | Boots | Yes |

## FPS guidance

- Record a realistic range during gameplay, not a single best spike.
- Use the same test area where possible.
- Use `N/A` when FPS cannot be measured or the game never reaches gameplay.
- Do not claim a game runs at full speed from an isolated menu result.

## Context matters

A rating is tied to a tested setup. State the device, firmware, Rt:Core version, profile, game region/revision and any custom settings. A result for PAL should not automatically be copied to NTSC or JPN.

## Aggregated card vs. individual test

The card is an overview across the available reports; its rating is not a promise that every report has the same result. Open the game to inspect each entry before applying a profile or recommending a game.
