# Visual Assets

Run `python3 tools/asset_inventory.py` to generate JSON and CSV inventories with hashes, file sizes and image dimensions (Pillow optional). Add `--contact-sheet` to create a contact sheet when Pillow is installed.

Generated reports are local artifacts under `artifacts/asset-audit/`. Keep them out of commits unless intentionally requested.

Do not add ROMs, BIOS, firmware, copyrighted game artwork, personal screenshots or secrets. Preserve attribution and licenses for third-party resources.
