HOW TO READ THE ARCHIVE

Three different sources.

The file path tells you what the INI is for. Do not install or overwrite files simply because they share a Game ID.

DOLPHIN SYSTEM DATABASE

Official per-game entries

Files under Sys/GameSettings/. These are Dolphin's bundled game-specific defaults and compatibility settings.

Rt:CORE CUSTOM OVERRIDE

Handheld-specific overrides

Files under the installed emulator's GameSettings/ directory. These are project-supplied custom overrides and should be checked against the current build.

Rt:UI WORKSHOP

Editable workshop presets

Files under workshop/gamesettings/. A folder may include base, speedhack, custom patch and metadata INIs used by Rt:UI.

Important: GameSettings uses Dolphin's game-specific section names. Video hacks belong under [Video_Hacks], not [Hacks]. The latter is silently ignored in a GameSettings file.
