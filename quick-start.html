MUST KNOW · H700 FIELD GUIDE

Andromeda Quick Start.
No guesswork. No magic.

Install the correct Dolphin Rt:Core integration on muOS 2606.0 Andromeda, get Rt:UI through first boot, and understand the device-specific traps that caused real setup failures.

This guide targets the RG35XX H / Allwinner H700 and the Andromeda release line. Jacaranda v11.5.x is a separate legacy package family. Do not mix firmware packages.

Back up before touching the SD card

Back up the full card where practical, plus saves and existing Dolphin configuration. Keep the previous package and configuration available for rollback. Never use “delete the whole Dolphin folder” as a generic troubleshooting step.

Confirm the firmware and package line

Verify the device is running muOS 2606.0 Andromeda. Download the matching Andromeda .muxupd from the GitHub Releases page. Jacaranda v11.5.1 is a different legacy line.

A registration detector does not make an Andromeda package compatible with Jacaranda. Firmware matching is not optional.

Install the update through Archive Manager

Copy the MUXUPD into the SD card's ARCHIVE/ directory. Open muOS Archive Manager and install it. Let the installation complete before launching the frontend. Do not unpack the update manually over a live installation unless the release instructions explicitly require it.

Provide the matching Dolphin executable

The update package does not necessarily contain the Dolphin emulator executable. The expected location is /opt/muos/share/emulator/dolphin/dolphin. Use the AArch64 build intended for the same release and target. Never pair an executable from one build with a different Sys/ resource tree.

The emulator binary and its Sys/ resources are a matched pair. A valid ELF file alone does not prove the runtime can start.

Check resources, fonts and libraries

Keep the Dolphin Sys/ directory from the same build, including GameSettings, DSP and font resources. Missing GameCube/Wii fonts can cause confusing text or startup symptoms. Verify the frontend's private libraries are present and resolve on the H700. Do not “fix” a missing library by copying random desktop libraries into the handheld.

Launch Rt:UI and let the boot tasks finish

Open Dolphin Rt:Core from Applications. The frontend can perform background tasks such as library indexing, bundled GameSettings deployment and selected database/cheat synchronisation. These tasks are asynchronous; do not assume the interface has frozen just because a scan is still running. Use Rt:System Status Center to inspect the actual task state.

Press M to expand the header into Rt:System Status Center. It reports Wi-Fi, portal/Sunshine health, database download state, GameSettings deployment, library indexing and background operations. Wi-Fi link status and remote service health are deliberately separate.

Set ROM folders and let the library scan complete

In Content Explorer, select the folders containing your own GameCube and Wii dumps. The boot scan is handed off to the Library view and continues incrementally. If you change ROM roots, use the folder controls and allow the scan to finish; duplicate paths are normalized and combined roots should remain visible.

Assign a core profile before launching

Open Core Assignment and start with Default or Rt:Prime Standard. Do not begin with the most aggressive speedhack profile. Check the exact title and region in Compatibility List before changing settings. Apply one change at a time and record the result.

Keep official Dolphin Sys/GameSettings/ and Sys/Load/GraphicMods/ resources intact. Mod Vault's “All Games” means eligible for all games, not globally enabled; graphics mods are enabled per Game ID.

Verify controller input and hotkeys

For the built-in H700 pad on the documented Andromeda SDL path, the device is SDL/0/muOS-Keys. The face-button indices are intentionally not in physical label order: A is Button 1 and B is Button 0. Use the table below rather than guessing.

Test one known game and record evidence

Test a known lightweight GameCube title and then a Wii title. Check video, audio, input, frame pacing, memory pressure and clean exit. Record Game ID, region, device, exact firmware, Rt:Core build, profile and test duration in the Compatibility Database. CI is not a substitute for a physical RG35XX H test.

KNOWN TROUBLESHOOTING

Common problems.
Known first moves.

These are targeted checks from the project troubleshooting notes. Change one variable at a time and keep a rollback path.

Black screen on launch

Confirm the ISO is valid. Try Black Screen Fix, then Compatibility. Some games require per-game EFB access; Skies of Arcadia Legends requires MMU enabled per-game.

Texture flicker

On Panfrost, test disabling FastDepthCalc for that title. Do not blindly set SafeTextureCacheColorSamples to zero globally.

Choppy FMVs

Test SafeTextureCacheColorSamples = 512 for that specific Game ID. Avoid applying the tweak globally.

Crash during loading / OOM

Check memory pressure and texture packs. On a 1 GB handheld, keep HiresTextures disabled globally and enable only per-game when justified.

Low FPS

Start by testing Performance or Rt:Boost Lite, verify Fastmem and shader compilation settings, reduce internal resolution and keep MSAA/SSAA conservative.

Input / hotkey mismatch

Verify whether the controller is native SDL or keyboard-emulated. Do not launch gptokeyb for a native SDL profile. Check the L3 index 11 and Andromeda button map.

Library appears stuck

Boot ROM scanning is incremental and may continue after the intro. Check the Status Center and allow the active scan to hand off to Library. Avoid starting overlapping rescans.

GameSettings did not apply

Check the exact Game ID folder and deployed Config/GameSettings file. Dolphin expects [Video_Hacks], not [Hacks], for game-specific video hacks.

Graphics mods not active

Preserve Sys/Load/GraphicMods. All Games is an eligibility flag, not global activation. Enable each mod per Game ID in Mod Vault.

Safe recovery rule: preserve saves, user settings and logs. Capture the exact error and package/build identity before reinstalling. Do not delete broad configuration directories as a first response.
