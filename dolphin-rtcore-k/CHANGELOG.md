# Changelog

## 0.2.0
- All text (docs, scripts, EmulationStation option labels) is now English.
- `install.sh` can download the release files from the repo (`--update`, or automatically when `core/dolphin` is missing); `get.sh` is a single-file online installer.
- `rtcore.sh` helper: install / update / uninstall / run / status.
- Ready-to-go archive for `emulators/` with a launch script next to the folder.
- Illustrative screenshots in `docs/screens/`, generated by `docs/make_screens.py`.
- Updates never overwrite saves, memory cards, the Wii NAND, states, logs or settings.

## 0.1.0 - first Knulli port
Core: Dolphin Rt:Core 11.5.00 "Triptych" (custom 2412 build, aarch64). Target: Anbernic RG35XX-H, Knulli (Batocera).
- Launcher `bin/rtcore-k.sh` with no absolute paths: everything is relative to the release folder.
- EmulationStation integration: `wii` and `gamecube` systems, Rt:Core profiles selectable as per-game "cores".
- Per-game options: controller sticks, Wiimote position, game settings, safe exit, HD textures, cheats, FPS.
- Safe exit (Select + Start or Menu + Start) with a grace period so Dolphin closes cleanly before any kill.
- Full SDL mapping for the pad (both sticks, d-pad on the hat) in `config/devices/`.
- Fix: the Wii `2joy` profiles had the closing backtick missing on the four `Nunchuk/Stick/*` lines.
- Fix: `Dolphin.ini.default` pointed at `/run/muos/...` (a RAM disk on Knulli: saves lost at reboot); paths are now rewritten at every launch to live inside `core/`.
- Pad name in the profiles is rewritten at every launch (`SDL/0/<PAD_NAME>`).
- Installer / uninstaller, pixel-art logos for the theme (ARCADEPLANET: `_art/Colorlogos`).
- `legacy-muos/`: the original muOS launcher, tasks, info files and LOVE UI.
